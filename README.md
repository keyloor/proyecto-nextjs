# Catálogo de cursos en Next.js

Proyecto e Investigación #2 de IF0009 Desarrollo de Software IV, Universidad de Costa Rica.

Integrantes: Keylor Barrantes, Sebastián Marín Fernández y Juan Pablo Jiménez Vargas.

## Requisitos

- Node.js 20.9 o superior. Para revisar la versión: `node --version`.

## Cómo ejecutarlo

```bash
git clone https://github.com/keyloor/proyecto-nextjs.git
cd proyecto-nextjs
npm install
npm run dev
```

Después abrir <http://localhost:3000>.
